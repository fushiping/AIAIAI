# 傅先生AI项目VIP

面向国内 B 端访客的项目展示、资料分发与合作咨询系统。访客端与管理后台共用同一套 REST API，但入口和界面完全分离。

## 在线地址

- 访客端：https://www.yijianbaowen.cn/vip/
- 管理后台：https://www.yijianbaowen.cn/vip/admin/
- 源码仓库：https://github.com/fushiping/AIAIAI

## 已实现能力

- 访客端：深蓝商务视觉、首屏内容、分类筛选、动态项目卡片、项目详情弹窗、软件/资料下载、信任保障、合作咨询、响应式布局。
- 联系转化：右侧固定悬浮联系入口、二维码弹窗、管理员头像与身份标识；图片和文字均可在后台实时维护。
- 项目管理：搜索、分类筛选、状态筛选、排序、批量上下架/删除、新增、编辑、上下架切换。
- 文件管理：一个项目可上传多个软件包和多个资料，支持自定义展示名、重命名、替换、删除、管理员测试下载。
- 内容运营：项目分类 CRUD、显示状态、排序；首页文案、信任保障、合作流程、联系方式、页脚和全部公共界面文字配置。
- 数据统计：访问量、软件下载、资料下载、咨询数量、30 天趋势、项目访问排行和单项目时间区间数据。
- 咨询管理：留言查看、搜索、筛选、已读状态、处理状态和内部跟进备注。
- 权限与安全：总管理员、子管理员、细粒度权限、修改密码、HttpOnly 会话、登录限流、上传格式白名单、一次性下载令牌、单 IP 每日下载限制、下载前留资开关。
- 存储：SQLite 持久化数据；上传文件保存在 `storage/`，前台不会直接暴露静态文件路径。

## 技术结构

```text
.
├─ server/                 Express REST API、SQLite、鉴权与文件分发
│  ├─ routes/public.js     访客接口
│  ├─ routes/admin.js      运营后台接口
│  ├─ services/storage.js  本地存储与对象存储扩展点
│  └─ seed.js              首次启动初始化示例内容
├─ public/
│  ├─ index.html           访客端单页
│  ├─ assets/              访客端样式、脚本、封面
│  └─ admin/               管理后台单页
├─ data/                   运行时数据库与会话密钥（不提交版本库）
├─ storage/                运行时上传文件（不提交版本库）
├─ docs/                   API 与部署文档
└─ scripts/                接口与浏览器验收脚本
```

前端是独立的静态单页应用，通过 `/api/public/*` 和 `/api/admin/*` 与后端通信，不需要和服务器端代码混合。当前实现无需前端构建步骤，便于直接部署；后续也可将 `public/` 替换为 React/Vue 工程，而无需修改 API。

## 快速启动

要求 Node.js `>= 22.5`，推荐 Node.js 24。

```bash
npm install
npm start
```

默认访问地址：

- 访客端：`http://127.0.0.1:18930/`
- 管理后台：`http://127.0.0.1:18930/admin/`

当前工作目录中的 `.env` 因本机 `18930` 已被其他服务占用，配置为 `18931`：

- 访客端：`http://127.0.0.1:18931/`
- 管理后台：`http://127.0.0.1:18931/admin/`

首次启动会创建示例分类、项目、可下载演示文件和总管理员：

```text
账号：admin
密码：FushiVIP@2026
```

登录后请立即通过右上角账号菜单修改密码。数据库已存在时，修改 `.env` 中的管理员账号或密码不会重置已有账号。

## 配置

复制 `.env.example` 为 `.env` 后按实际环境修改：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `18930` | HTTP 服务端口 |
| `NODE_ENV` | `development` | 正式环境必须设置为 `production` |
| `PUBLIC_ORIGIN` | 空 | 正式站点 Origin，如 `https://vip.example.com` |
| `TRUST_PROXY` | `0` | 经 Nginx 等反向代理时设置为 `1` |
| `ADMIN_USERNAME` | `admin` | 仅在首次初始化数据库时使用 |
| `ADMIN_PASSWORD` | `FushiVIP@2026` | 仅首次初始化时使用，正式环境务必替换 |
| `ADMIN_DISPLAY_NAME` | `超级管理员` | 总管理员显示名称 |
| `JWT_SECRET` | 自动生成 | 可显式配置；留空时保存到 `data/.jwt-secret` |
| `SESSION_HOURS` | `12` | 后台登录有效期 |
| `MAX_PROJECT_FILE_MB` | `200` | 单文件上传上限 |
| `MAX_COVER_FILE_MB` | `5` | 项目封面上传上限 |

## 日常运营路径

1. 进入“项目管理”，新增项目并填写前台展示内容。
2. 上传封面，保存项目。
3. 在项目列表点击“文件”，上传软件安装包或资料，并设置前台展示名。
4. 打开“立即上架”开关，访客端会读取最新接口内容。
5. 在“内容与设置 → 首页文案”的“首屏精选项目”中，从已上架项目里选择首页主视觉展示项目。
6. 在“内容与设置”中调整首页文案、联系方式、版权和下载规则。
7. 在“内容与设置 → 全站文字”中修改导航、按钮、表单占位提示、弹层层级文字、操作提示和页脚链接等公共文案。
8. 在“咨询留言”中处理线索并记录内部备注。

后台保存内容后会通过 SSE 实时推送到当前访客页面；同时保留 60 秒轮询和页面重新聚焦检查作为断线兜底。无需修改代码或重新部署。

## 测试

服务启动后，在新终端运行：

```bash
npm run check
npm run test:smoke
npm run test:visual
```

- `test:smoke` 覆盖登录、鉴权、项目/分类/文件 CRUD、全站文字、悬浮联系图片、文件替换、格式拦截、留资下载、IP 限制、统计、权限隔离和密码修改等 34 个场景。
- `test:visual` 使用本机 Microsoft Edge，检查桌面端/移动端截图、横向溢出、浏览器控制台错误和真实下载事件。截图保存在 `test-output/`。

若服务端口不是 `18931`，先设置测试地址：

```powershell
$env:TEST_BASE_URL="http://127.0.0.1:你的端口"
npm run test:smoke
```

## 数据与备份

生产环境至少备份以下两类内容：

- `data/app.db`
- `storage/`

SQLite 使用 WAL 模式，建议停机或使用 SQLite 在线备份命令复制数据库，避免只复制单个 `app.db` 而遗漏 WAL 数据。

更完整的生产部署、Nginx、HTTPS、PM2 和对象存储扩展说明见 [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)，接口清单见 [docs/API.md](docs/API.md)。
